# project-etl-data

Minimal ETL project structure focused on data quality (before/after cleaning).

Structure:
- `data/raw/` — original data
- `data/processed/` — cleaned data
- `notebooks/` — analysis notebooks
- `src/` — `etl.py`, `utils.py`
- `reports/` — figures and final report

# Iris Data Analysis – ETL

Proyecto de análisis de datos end-to-end aplicando un flujo ETL sobre el dataset Iris.

## Tecnologías
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Estructura
- `data/raw` → datos originales  
- `data/processed` → dataset limpio  
- `notebooks` → exploración, limpieza y análisis  
- `reports` → gráficas y reporte final  

## Flujo de trabajo
1. Exploración del dataset  
2. Limpieza y validación de calidad  
3. Análisis exploratorio y visualización
